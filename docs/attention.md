# Inspecting attention gates

Open [check_attention.ipynb](../notebook/check_attention.ipynb) with the `rnet`
kernel. It inspects trained spatial gates without compiling, fitting or changing
network architecture, weights, labels or source files.

The default selects the explicit MouseFull v1 run previously evaluated. Change
`RUN_DIR` and `FOLD` for another fixed-split or CV checkpoint. Its saved
`training_state.json` determines the selected checkpoint; file modification times
are not used. A weights-only file needs the experiment configuration that created
it. Rebuilding uses its original architecture and fitting outputs, including
`regions_logits` where applicable; no transfer initialization is performed.

For a complete legacy export, set `RUN_DIR=None`, `CHECKPOINT_KIND="model"`, and
`MODEL_FILE` to a trusted `.h5` or `.keras` file. An experiment file is optional
for complete exports. Without it, set preprocessing explicitly using
`LEGACY_SPACING_MM`, `LEGACY_CORRECT_UNITS` and `LEGACY_NORMALIZATION`. The older
bundled models accept flexible spatial dimensions: `LEGACY_PATCH_SIZE` then
chooses the inspected patch, defaulting to `(80, 80, 80)`. Fixed-input models use
their own patch shape; saved configurations provide the patch size otherwise.

Choose a reproducibly sampled normalized scan or explicit MRI/optional ROI files.
Use MRI already corrected with N4 where that was the training convention.
Reorientation uses the shared RIA reference in `example/RARE/TBI_fm_19_49/Anat/`.
MRI and masks undergo identical spatial operations, with linear MRI and nearest
neighbor label interpolation. Source ROI IDs are preserved for the optional
contours. There is no random augmentation. The default crop is deterministic;
`PATCH_CENTER` selects a different location in the processed volume.

`attention_gate_table` identifies sigmoid weights feeding skip-feature
multiplication through upsampling/repetition layers. It does not depend on
autogenerated layer names, and excludes classifier and brain-mask sigmoids.
Attention-disabled models report that no supported gates exist. The four gates
are listed from coarse to fine; their native sizes are resolved during inference
for flexible-input exports.

`inspect_attention` forwards a patch with `training=False`. It reads gate weights
before channel repetition, at the spatial resolution used to multiply skip
features. For overlays, coarse weights are linearly lifted to the patch grid with
pixel-edge alignment, retaining their real `[0, 1]` values. This interpolation
affects only visualization. Maps are not min-max rescaled independently.

`attention_figure` builds a native Plotly slice slider, showing the same MRI slice
under each gate with one fixed attention color scale. Hover reads its displayed
weight. Optional cyan contours select an original ROI ID (`GT_REGION=1` for
lesion), or all source foreground with `None`. Axis labels identify anatomical
directions from the patch affine. `VIEW_AXIS`, `MAX_SLICES` and opacity are
visible settings; the figure uses `renderer="vscode"`, without ipywidgets or HTML.

These are patch-context-dependent, class-shared spatial coefficients. They are
not transformer attention matrices, class probabilities, calibrated importance,
or causal explanations. This notebook does not create whole-volume aggregated
attention maps, evaluate segmentation accuracy or infer unavailable ground truth.

## Optional classifier Grad-CAM

The classifier section exposes `RUN_CLASSIFIER_GRADCAM=False`. Enable it to
explain one patch's binary classifier output, reusing its preprocessed MRI and
optional original-ID ROI contours. No compilation or training is performed.
`GRADCAM_TARGET` selects `"TBI"`, `"SHAM"`, or `"predicted"`; predicted uses TBI
only above 0.5, matching the existing patch decision rule.

`classifier_feature_table` lists spatial features on the classifier branch.
`GRADCAM_LAYER=None` selects the tensor immediately before global average pooling,
normally the bottleneck. The decoder/gate tensors are not ancestors of this
classifier, so they cannot explain its output. Other listed encoder tensors can
be selected explicitly. A model without the classifier is skipped, while a
classifier model without attention gates can still use this section.

`classifier_gradcam` reconstructs the final pre-sigmoid scalar from the Dense
input, kernel and bias without editing its activation. TBI uses that logit; SHAM
uses its negative. This avoids sigmoid saturation in the differentiated score.
The implementation averages score gradients over the three spatial dimensions,
uses them to weight feature channels, sums channels and retains positive evidence
with ReLU. It adapts the [original Grad-CAM method](https://arxiv.org/abs/1610.02391)
and [Keras example](https://keras.io/examples/vision/grad_cam/) to 3D binary scores.

The positive native map is divided by its own maximum for display, then linearly
lifted onto the MRI patch grid. Its colors represent **relative attribution**,
unlike the gate maps' actual sigmoid weights. Color magnitudes cannot establish
stronger attribution between subjects. A summary retains raw CAM extrema, its
positive peak, gradient magnitude, feature resolution, selected target, logit and
patch TBI probability. Zero gradients and absent positive evidence receive explicit
statuses and zero maps, without division by zero or invented contrast.

The separate `gradcam_figure` uses the same Plotly viewer and geometry, with titles
and hover labels identifying attribution. Its axis, slice limit, opacity and GT
settings are independent of the gate display. Both functions use `training=False`;
model weights, batch-normalization state and classifier activation remain unchanged.

This explains a patch score, not the whole-volume classifier's majority vote or
any segmentation class. A coarse or empty map is not evidence of feature
irrelevance. These exploratory figures can help inspect the reviewer's classifier
concern, but cannot prove causality or rule out cohort/acquisition confounding.

Tests exercise exact sigmoid scale, unchanged model state, attention-disabled
graphs, flexible inputs, weights and full-model loading, paired MRI/GT geometry,
slice frames, and the notebook's center/custom-crop paths. The three bundled
legacy exports were also loaded and inspected on synthetic patches read-only.
Grad-CAM tests additionally check analytical opposite-class evidence, saturated
sigmoids, frozen models, zero maps, disconnected features, unchanged state,
classifier-free models and the optional notebook cells.

## Optional segmentation Grad-CAM

Enable `RUN_SEGMENTATION_GRADCAM` in the final section. It works with or without
the auxiliary classifier and attention gates. Choose `SEGMENTATION_HEAD="regions"`
and a **model channel** in `SEGMENTATION_CLASS_INDEX`, or choose `"brain_mask"`
(channel zero). The displayed channel table maps the saved model's channels to
original ROI IDs, including merged classes. For complete legacy models without
configuration, set `SEGMENTATION_LEGACY_GT_IDS` explicitly for the chosen channel.

The target is the selected channel's **mean raw logit** over fixed voxels:

- `"all"`: the whole inspected patch, including when the region is not predicted.
- `"prediction"`: that class's argmax voxels, or positive sigmoid voxels for brain.
- `"provided"`: an aligned binary target mask. The notebook constructs it from
  available ROI annotations, with original IDs mapped to the selected channel.

Prediction masks are fixed before differentiation. Empty targets raise an error;
unannotated regions are not treated as empty GT. Normalized metadata controls GT
availability; explicit file inputs require the user to establish coverage. The
notebook's provided mode uses ROI annotations; the module also accepts an aligned
binary brain mask. No source labels or output activations are modified.

`segmentation_feature_table` defaults to the finest decoder features preceding
the ROI/brain projection. Other spatial ancestors of the selected head are listed
for explicit selection. Both ordinary softmax models and linear `regions_logits`
fitting graphs expose their existing pre-activation scores. The implementation
adapts [SEG-GRAD-CAM](https://arxiv.org/abs/2002.11434) to 3D and uses a mean instead
of a sum: for a fixed nonempty target this rescales the raw attribution by its
voxel count and leaves the maximum-normalized display unchanged.

Channel weights are mean spatial gradients, followed by the shared positive
Grad-CAM reduction and MRI-grid display. Diagnostics record the target, voxel
count, feature layer, raw score and map status. The independent Plotly slice
controls use `SEGMENTATION_VIEW_AXIS`, `SEGMENTATION_MAX_SLICES` and opacity.
These are patch attributions, not full-volume probabilities. Spatial gradient
averaging can lose localization detail and does not restrict the heatmap to the
target mask. A plausible map does not validate unannotated anatomy or establish
causal reasoning. Use the existing evaluation reports for quantitative accuracy.

Analytical tests check opposite-class maps, fixed prediction/annotation targets,
empty targets, channel bounds and geometry. Repository 3DR-Net and U-Net fitting
graphs are checked without training or changing weights/batch-normalization state.
