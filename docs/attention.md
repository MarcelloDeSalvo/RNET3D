# Inspecting attention gates

Open [check_attention.ipynb](../notebook/check_attention.ipynb) with the `rnet`
kernel. It inspects trained spatial gates without compiling, fitting or changing
network architecture, weights, labels or source files.

The default selects the explicit MouseFull v1 run previously evaluated. Change
`RUN_DIR` and `FOLD` for another fixed-split or CV checkpoint. Its saved
`training_state.json` determines the selected checkpoint; file modification times
are not used. A weights-only file needs the experiment configuration that created
it. Rebuilding uses its original architecture and fitting outputs, including
`regions_logits` where applicable; no transfer initialization is performed.

For a complete legacy export, set `RUN_DIR=None`, `CHECKPOINT_KIND="model"`, and
`MODEL_FILE` to a trusted `.h5` or `.keras` file. An experiment file is optional
for complete exports. Without it, set preprocessing explicitly using
`LEGACY_SPACING_MM`, `LEGACY_CORRECT_UNITS` and `LEGACY_NORMALIZATION`. The older
bundled models accept flexible spatial dimensions: `LEGACY_PATCH_SIZE` then
chooses the inspected patch, defaulting to `(80, 80, 80)`. Fixed-input models use
their own patch shape; saved configurations provide the patch size otherwise.

Choose a reproducibly sampled normalized scan or explicit MRI/optional ROI files.
Use MRI already corrected with N4 where that was the training convention.
Reorientation uses the shared RIA reference in `example/RARE/TBI_fm_19_49/Anat/`.
MRI and masks undergo identical spatial operations, with linear MRI and nearest
neighbor label interpolation. Source ROI IDs are preserved for the optional
contours. There is no random augmentation. The default crop is deterministic;
`PATCH_CENTER` selects a different location in the processed volume.

`attention_gate_table` identifies sigmoid weights feeding skip-feature
multiplication through upsampling/repetition layers. It does not depend on
autogenerated layer names, and excludes classifier and brain-mask sigmoids.
Attention-disabled models report that no supported gates exist. The four gates
are listed from coarse to fine; their native sizes are resolved during inference
for flexible-input exports.

`inspect_attention` forwards a patch with `training=False`. It reads gate weights
before channel repetition, at the spatial resolution used to multiply skip
features. For overlays, coarse weights are linearly lifted to the patch grid with
pixel-edge alignment, retaining their real `[0, 1]` values. This interpolation
affects only visualization. Maps are not min-max rescaled independently.

`attention_figure` builds a native Plotly slice slider, showing the same MRI slice
under each gate with one fixed attention color scale. Hover reads its displayed
weight. Optional cyan contours select an original ROI ID (`GT_REGION=1` for
lesion), or all source foreground with `None`. Axis labels identify anatomical
directions from the patch affine. `VIEW_AXIS`, `MAX_SLICES` and opacity are
visible settings; the figure uses `renderer="vscode"`, without ipywidgets or HTML.

These are patch-context-dependent, class-shared spatial coefficients. They are
not transformer attention matrices, class probabilities, calibrated importance,
or causal explanations. This notebook does not create whole-volume aggregated
attention maps, evaluate segmentation accuracy or infer unavailable ground truth.

Tests exercise exact sigmoid scale, unchanged model state, attention-disabled
graphs, flexible inputs, weights and full-model loading, paired MRI/GT geometry,
slice frames, and the notebook's center/custom-crop paths. The three bundled
legacy exports were also loaded and inspected on synthetic patches read-only.
